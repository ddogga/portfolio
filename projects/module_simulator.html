전력 관리 모듈 시뮬레이터 신규 개발

6종 전력 모듈을 멀티스레드로 동시 구동하는 모듈 시뮬레이터와, 이를 UDP 프로토콜로 감시·제어하는 시뮬레이터 개발

Period 2023.08 – 2024.07
Role · Team Backend · 진행 인원 : 2명
Tech Stack JavaSpring Boot Java DatagramSocket(UDP)WebSocket thymeleaf
§01Contributions
UDP 기반 전력 모듈 통신 프로토콜 구현
  • 실제 장비와 동일한 UDP 바이너리 프로토콜을 구현하여 전력 모듈과 통신
  • Polling 방식으로 전류·전압 등 측정값을 주기적으로 수집하고, 원격 스위치 제어 기능 구현
  • 실제 장비와 동일한 통신 환경을 시뮬레이션하여 기능 검증 지원
전력 모듈 시뮬레이터 개발
  • 규격에 맞는 명령 코드를 수신하면 스위치 제어 및 측정값을 응답하는 가상 장비 구현
  • 실제 장비 없이도 개발 및 테스트가 가능한 시뮬레이션 환경 구축
  • 장비 프로토콜 검증 및 기능 테스트 효율 향상
관제 시뮬레이터(UI) 개발
  • Thymeleaf 기반 UI를 구현하여 가상 장비를 제어하는 관제 화면 개발
  • 사용자 입력을 규격 프로토콜로 변환하여 장비에 전송하고 응답 결과를 실시간 표시
  • 장비 제어와 상태 모니터링 기능 제공
멀티스레드 기반 장비 동시 구동
  • 하나의 프로그램에서 6종의 전력 모듈을 동시에 시뮬레이션하도록 멀티스레드 구조 설계
  • 장비별 독립적인 스레드를 운영하며 생명주기와 동시성 이슈 관리
  • 다수 장비를 동시에 구동하는 환경에서도 안정적인 시뮬레이션 지원
요청-응답 순서 보장을 위한 비동기 제어
  • Timer 기반 비동기 통신 구조에서 요청과 응답의 순서를 관리하는 로직 구현
  • 응답이 도착하기 전에는 다음 명령을 제한하여 요청-응답 동기성 보장
  • 타임아웃 처리 및 통신 안정성 향상
