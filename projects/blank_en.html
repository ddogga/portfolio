§01Contributions
OAuth2 + JWT를 활용한 소셜 로그인 통합 구현
  • Provider마다 상이한 사용자 정보 응답 구조를 공통 모델로 변환하는 구조를 설계.
Access Token / Refresh Token 분리 설계로 토큰 탈취 대응과 서버 측 통제 확보
  • Access Token은 30분 단기 수명으로 탈취 시 피해 범위를 제한
  • Refresh Token은 Redis에 저장하고 재발급 시 교체해 로그아웃과 강제 만료가 가능하도록 구현
  • Redis GETDEL로 재발급을 원자적으로 처리해 동일 토큰의 중복 재발급을 방지
OAuth2 인가 요청 저장소를 쿠키 직렬화 방식에서 Redis + 랜덤 키 방식으로 전환
  • 클라이언트가 조작 가능한 쿠키 값을 그대로 Java 역질렬화 하던 보안 취약점을 제거
