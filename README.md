# 이하연 · 백엔드 개발자 포트폴리오

🔗 **사이트 바로가기:** https://ddogga.github.io/portfolio

Java / Spring Boot 기반 백엔드 개발자 이하연의 개인 포트폴리오 웹사이트입니다.
GitHub Pages로 정적 호스팅되어 있으며, 다크/라이트 테마를 지원합니다.

## 구성

- `index.html` — 메인 페이지 (Profile / Experience / Side Projects)
- `projects/` — 각 프로젝트 상세 페이지
  - `substation_automaion_monitoring.html` — 변전 자동화 및 모니터링 어플리케이션 유지보수
  - `file_editor_project.html` — 파일 편집 어플리케이션 신규 개발
  - `module_simulator.html` — 전력 관리 모듈 시뮬레이터 신규 개발
  - `opensource-analysis.html` — 배전 자동화 오픈 소스 분석
  - `market_query_performance.html` — 조회 성능 최적화 실험 프로젝트 (개인)
- `assets/` — 공통 CSS / JS / 이미지 리소스

## 기술 스택

Java, Spring Boot, JPA, QueryDSL, PostgreSQL, MongoDB, Redis, Docker, JNI, MSA
